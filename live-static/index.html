INSIDE LUMA STUDIO

What Luma Studio can do.

Build layered images, refine every detail, and keep creative decisions editable.

21features to explore

Full product inventory. Web, native and experimental capabilities vary by edition. Hosted generative edits require authentication and network access. Desktop RAW support and native processing go beyond the browser. PSD/PSB conversion is explicitly scoped rather than universally lossless.

Layers & colorPaint, select & composeRAW & Photoshop workflowsProduction & creative continuity
01

Layers & color

6 features

  • Complete layer system

    Raster, text, shape, path, group, adjustment, and smart-object layers.

    Try this in an example

  • Advanced blending

    27 Photoshop layer blend modes, opacity and fill controls, multiple blend passes, and Blend If.

  • Masks and effects

    Layer masks, clipping masks, layer effects, and editable smart filters.

    Try this in an example

  • Nondestructive adjustments

    Levels, Curves, HSL, exposure, tone, and color adjustments.

    Try this in an example

  • Precision color

    8-, 16-, and 32-bit precision masters; sRGB, Display P3, and linear sRGB working spaces.

  • Color management

    Supported ICC profiles, soft proofing, and gamut warnings.

02

Paint, select & compose

7 features

  • Painting

    Pressure- and tilt-aware brushes, symmetry, painting, erasing, and mixer tools.

  • Custom brushes

    Capture full-color image tips from the canvas or an uploaded image; use tint or stencil modes and save brush libraries inside projects.

  • Retouching

    Clone, healing, removal, dodge/burn, blur/sharpen, smudge, and sponge tools.

  • Selections

    Marquee, lasso, polygonal, magnetic, color, quick, text-mask, and local semantic selections.

  • Selection refinement

    Feathering, smoothing, contrast, and edge shifting.

  • Typography

    Editable text, paragraph and vertical type, and text on curved paths.

    Try this in an example

  • Vector and composition tools

    Pen and direct selection, shapes, perspective adjustments, cropping, straightening, and transforms.

03

RAW & Photoshop workflows

3 features

  • RAW development

    Supported DNG sensor development with retained source data, white balance, exposure, and highlight controls.

  • Desktop camera support

    Additional camera formats through available macOS codecs, with clearly identified preview fallbacks.

  • Photoshop interchange

    PSD/PSB preflight, preservation of supported text/vector/adjustment metadata and smart-object payloads, plus conversion warnings.

04

Production & creative continuity

5 features

  • Versioning and workspace

    Branching history, recovery, multiple documents, contextual properties, custom workspaces, and shortcuts.

    Try this in an example

  • Production tools

    Actions, batch ZIP export, named layer comps, channel inspection, and artboard-region export.

  • AI-assisted editing

    Local segmentation/matting and authenticated hosted generative edits, including masked regions and variations.

  • Saving and export

    Editable .luma projects and PNG, JPEG, and WebP outputs.

    Try this in an example

  • Desktop extensions

    Declarative action packages, native file dialogs, and native high-precision compositing for eligible documents.
