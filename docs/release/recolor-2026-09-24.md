# Advanced Recolor — 2026-09-24

## Access

Select one unlocked raster layer, then **Layer → Recolor…** or search for
**Recolor** in the command palette. Shortcut: **⌘⌥R** on Mac / **Ctrl+Alt+R**.
The native menu, browser shortcut and command palette use the same command.
No new permanent tool or sidebar is introduced.

## Controls

- Sample original pixels in the preview, use the suggested image palette, or
  enter a color. Combine up to 16 targets and 8 protected colors.
- Match perceptual color distance (OKLab) or hue family. Tune tolerance and
  smooth color-distance transitions; optionally invert the target range.
- Narrow by saturation/lightness and respect the existing document selection.
- Replace color, preserve HSL lightness/shading, shift hue/saturation/lightness,
  desaturate, remove matching colors to transparency, or isolate the targets.
  Protected colors remain untouched even when isolating.
- Compare Original, Result and the matching alpha mask. Source pixels are
  sampled regardless of which view is displayed.
- White-background, black-background and red-to-blue presets; save up to 12
  named custom presets locally. Presets belong to this browser/device, not to
  the project or a cloud account.

## Outputs and safety

Default output creates a recolored copy and hides, but does not delete, the
original. Other outputs modify layer pixels, create a selection (replace/add/
subtract/intersect), or apply a keep/remove mask. Existing raster masks are
intersected with the new mask. Selection/mask outputs use the matching range,
not the chosen color operation or strength.

Applying is one undo operation. Ordinary raster, sparse-alpha and history
serialization preserve the results; this is not a new live adjustment layer.
Edits or document switches invalidate pending work. Window/viewport-only
redraws do not. Computation yields between chunks; live preview uses a worker
with debouncing and cancellation. Closing without applying changes no pixels.

The source layer must be full-resolution **8-bit sRGB, at most 50,000,000
pixels and at most 16,384 pixels on either axis**. RAW/high-depth masters,
disk-backed proxies, projected layers and noninvertible transforms are refused
explicitly. No automatic rasterization or downconversion occurs. The transformed
selection/mask footprint is also limited to 50 MP, stored in sparse document
coordinates. Known allocations use the engine's 1 GiB admission ceiling; this
is not a claim to cap total OS process memory.

### 50 MP follow-up

Application now reads 256×256 source tiles, not a document-sized ImageData or
selection array. Pixel output stages only changed before/after tiles and a
copy-on-write precision surface; it publishes once after all work succeeds.
Copy output still requires a full destination canvas and precision master.
Selection/mask output builds sparse local alpha, then maps it into sparse
document alpha tile by tile. Mask history stores mask-only snapshots rather
than retaining unrelated full-resolution layer bitmaps.

The dialog reports tile progress and provides **Cancel operation**. Cancellation,
stale documents, admission failures and injected commit failures preserve the
original. Large results also preflight the existing save-with-history memory
budget before publication. A 50 MP size allowance is **not unrestricted dense
50 MP editing**: broad changes, extra copies, existing history and resident
layers can still cause a safe refusal. The 1 GiB ceiling has not been raised.

Regression coverage includes a 10,000×5,000 bitmap with localized colored
pixels: bounded reads, changed-tile history under 1 MiB, pixel apply/undo/redo,
save/reopen, sparse selection/mask creation, mask history and mask save. These
are large-geometry sparse-content fixtures, not representative 50 MP camera
photo benchmarks or a guarantee that every dense 50 MP project saves.

The preview shows source-layer pixels, not the final effects/masks/composite.
Existing layer effects, masks and affine transforms remain attached. Soft
transition is color-distance falloff, not spatial blur or edge decontamination.
RGB replacement is display-referred sRGB and HSL shading preservation is not
a physically based relighting or perceptual color-proofing guarantee.
